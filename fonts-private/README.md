# Private fonts

Drop `.ttf` or `.otf` files here for fonts you own but aren't allowed to redistribute (for example a
Pangram Pangram licence). The build copies them into your APK and they appear first in
Settings > Font, named after the file: `PP Neue Montreal.otf` shows as "PP Neue Montreal".

Everything in this folder except this README is git-ignored. Don't publish an APK built with fonts
whose licence doesn't allow it.
